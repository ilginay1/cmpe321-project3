# AI Usage Report

For this project, we used AI tools as learning and development support. 

## How AI Was Used

AI was used to support the implementation and organization of the project, especially for:

- generating initial code skeletons for the modular DBMS structure,
- adding code documentation and explanatory comments,
- creating and improving test scripts,
- helping collect and structure test results,
- improving report text and explanation sections,
- cleaning up and refactoring code for readability,

## What Was Modified Manually

All AI-refined code was reviewed before being accepted. We manually tested the implementation with different input files and configuration settings. Several bugs and inconsistencies were found and fixed during testing, especially related to output formatting, logging, statistics, index behavior, persistence, and range search validation.


## Testing and Verification

AI was also used to help design test cases and test scripts. However, the results were verified by running the project locally. 
The final behavior was checked manually using terminal outputs and generated result files.

## Report and Documentation Support

AI was used to improve the wording and structure of the report sections. 

## Responsibility Statement

AI tools were used as support tools, not as a replacement for understanding the project. We reviewed, tested, and modified the generated code ourselves. We are able to explain the implemented components, the design decisions, and the behavior of the system.
